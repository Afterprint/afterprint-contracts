# Security Policy

## Audit status

These contracts have **not** undergone an independent security audit. They are deployed to Stellar Testnet only. Do not deploy to Mainnet or rely on them to protect real value or real evidentiary integrity claims without an audit first.

## Reporting a vulnerability

Email **chijiokejoseph20242@gmaill.com** with a description of the issue and reproduction steps. Do not open a public GitHub issue for security vulnerabilities — this gives an attacker a head start before a fix ships.

You should get an acknowledgement within 5 business days. Once a fix is available, we'll coordinate disclosure timing with you.

## Scope

In scope: the five Soroban contracts in `contracts/`. Out of scope: the off-chain services in `afterprint-api` and `afterprint-ai` (report those in their own repos), and the Stellar network/SDK itself.
